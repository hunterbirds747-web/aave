# BTC 价格小组件(iOS)

![三种尺寸预览](preview.png)

提供两种方式:

| 方式 | 效果 | 需要 |
|---|---|---|
| **A. Scriptable 小组件(推荐)** | 真正的主屏幕 / 锁屏小组件,自动刷新,带 24 小时走势图,4 种主题 | 免费 App「Scriptable」 |
| **B. 快捷指令** | 点一下或喊 Siri 弹出价格 | 系统自带「快捷指令」 |

数据来自 CoinGecko 免费接口,不需要注册或 API Key。

> 预览图是在电脑上模拟 Scriptable 渲染出来的,用的是 2026-11-10 的真实行情。iPhone 上会用系统字体和系统图标,细节会略有差别。

---

## A. Scriptable 小组件

### 安装
1. App Store 下载 **Scriptable**(免费)。
2. 打开 Scriptable → 右上角 **+** 新建脚本。
3. 把 [`BTC-Widget.js`](./BTC-Widget.js) 的全部内容粘贴进去,点左上角标题改名为 `BTC`。
4. 点右下角 ▶ 运行一次,能看到预览说明成功。

### 从旧版更新
打开 Scriptable 里原来的 `BTC` 脚本,全选删除旧代码,粘贴新的 `BTC-Widget.js`,点 ▶ 运行一次。主屏幕上的小组件会在下次刷新时换成新样子,不用重新添加。

### 添加到主屏幕
1. 长按主屏幕空白处 →「编辑」→「添加小组件」。
2. 搜索 **Scriptable**,选择 小 / 中 / 大 尺寸,添加。
3. 长按刚加的小组件 →「编辑小组件」→ **Script** 选 `BTC`。

### 添加到锁屏
长按锁屏 →「自定」→ 锁屏 → 点小组件区域 → 选 Scriptable(矩形 / 圆形 / 行内)→ 再点它把 Script 设为 `BTC`。

### 换主题

![四种主题](preview-themes.png)

长按小组件 →「编辑小组件」→ 在 **Parameter** 里填一个词:

| 填写 | 主题 |
|---|---|
| `night`(或不填) | 夜间:深色底,涨绿跌红 |
| `aurora` | 极光:紫色渐变 |
| `orange` | 橙色:比特币橙,白色线条 |
| `light` | 浅色:白底 |

也可以填中文:`夜间`、`极光`、`橙色`、`浅色`。每个小组件可以单独设置主题。

### 各尺寸显示内容
- **小号**:价格、24 小时涨跌幅、走势图,右上角是数据的更新时间
- **中号**:再加上 24 小时涨跌金额
- **大号**:再加上时间刻度、24 小时最高 / 最低、市值、成交额
- **锁屏**:矩形显示价格和涨跌;圆形显示 `₿ 73.6k` 样式;行内显示一行文字

走势图上的虚线是 24 小时前的价格,线在虚线上方表示上涨。

### 可以修改的设置
在脚本开头:

```js
const COIN = "bitcoin";        // 改成 "ethereum"、"solana" 等
const NAME = "Bitcoin";        // 显示的名称
const SYMBOL = "BTC";          // 显示的代号
const CURRENCY = "usd";        // 改成 "cny" 显示人民币
const THEME = "night";         // 没填 Parameter 时用的主题
const RED_UP = false;          // 改成 true 就是红涨绿跌
const PREVIEW_SIZE = "medium"; // 在 App 里点 ▶ 预览的尺寸
```

### 说明
- 小组件多久刷新一次由 iOS 决定,一般 5–15 分钟,不是实时的。
- 网络不通或接口限流时,会显示上一次成功取到的数据,「更新于」显示的是那份数据的时间。
- 走势图画在小组件的背景上。如果主屏幕用的是「透明」或「着色」图标风格,系统会去掉小组件背景,走势图就不显示,只剩文字。

## B. 快捷指令版(不用装 App)

在「快捷指令」App 新建快捷指令,按顺序添加这些动作:

1. **URL**
   `https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd,cny&include_24hr_change=true`
2. **获取 URL 内容**
3. **获取词典值** → 获取 `bitcoin` 的值(来自「URL 的内容」)
4. **获取词典值** → 获取 `usd` 的值(来自上一步「词典值」)→ 长按结果改名为 `美元`
5. **获取词典值** → 获取 `cny` 的值(来自第 3 步)→ 改名为 `人民币`
6. **获取词典值** → 获取 `usd_24h_change` 的值(来自第 3 步)
7. **将数字取整** → 保留 2 位小数 → 改名为 `涨跌`
8. **显示提醒**(或「显示通知」/「显示结果」),内容:
   ```
   ₿ BTC
   $美元
   ¥人民币
   24h:涨跌%
   ```
   (把文字中的变量替换成上面命名的魔法变量)

命名为「比特币价格」后:
- 喊 **「嘿 Siri,比特币价格」** 就能播报;
- 在主屏幕添加「快捷指令」小组件,点一下即查看;
- 在「自动化」里设置每天定时运行 →「显示通知」,即可定时推送价格。
