# BTC 价格小组件(iOS)

提供两种方式:

| 方式 | 效果 | 需要 |
|---|---|---|
| **A. Scriptable 小组件(推荐)** | 真正的主屏幕 / 锁屏小组件,自动刷新,带 24h 走势图 | 免费 App「Scriptable」 |
| **B. 快捷指令** | 点一下或喊 Siri 弹出价格 | 系统自带「快捷指令」 |

数据来自 CoinGecko 免费 API,不需要注册或 API Key。

---

## A. Scriptable 小组件

### 安装
1. App Store 下载 **Scriptable**(免费)。
2. 打开 Scriptable → 右上角 **+** 新建脚本。
3. 把 [`BTC-Widget.js`](./BTC-Widget.js) 的全部内容粘贴进去,点左上角标题改名为 `BTC`。
4. 点右下角 ▶ 运行一次,能看到预览说明成功。

### 添加到主屏幕
1. 长按主屏幕空白处 → 左上角 **+** / 「编辑」→「添加小组件」。
2. 搜索 **Scriptable**,选择 小 / 中 / 大 尺寸,添加。
3. 长按刚加的小组件 →「编辑小组件」→ **Script** 选 `BTC`。
4. **When Interacting** 可选 `Open URL`,点小组件会打开 CoinGecko 行情页。

### 添加到锁屏(iOS 16+)
长按锁屏 →「自定」→ 锁屏 → 点小组件区域 → 选 Scriptable(矩形/圆形/行内)→ 再点它把 Script 设为 `BTC`。

### 各尺寸显示内容
- **小号**:价格 + 24h 涨跌幅
- **中号**:价格 + 涨跌幅 + 24h 走势图
- **大号**:同中号,走势图更大
- **锁屏**:矩形显示价格和涨跌;圆形显示 `₿ 98.5k` 样式;行内显示一行文字

### 自定义
脚本开头的设置区:
```js
const COIN = "bitcoin";   // 改成 "ethereum"、"solana" 等
const SYMBOL = "BTC";     // 显示的名称
const CURRENCY = "usd";   // 改成 "cny" 显示人民币
```

> iOS 会自己决定小组件刷新频率,一般 5–15 分钟左右刷新一次,不是实时的。网络失败时会显示上次的价格并标注「离线」。

## B. 快捷指令版(不用装 App)

在「快捷指令」App 新建快捷指令,按顺序添加这些动作:

1. **URL**
   `https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd,cny&include_24hr_change=true`
2. **获取 URL 内容**
3. **获取词典值** → 获取 `bitcoin` 的值(来自「URL 的内容」)
4. **获取词典值** → 获取 `usd` 的值(来自上一步「词典值」)→ 长按结果改名为 `美元`
5. **获取词典值** → 获取 `cny` 的值(来自第 3 步)→ 改名为 `人民币`
6. **获取词典值** → 获取 `usd_24h_change` 的值(来自第 3 步)
7. **将数字取整** → 保留 2 位小数 → 改名为 `涨跌`
8. **显示提醒**(或「显示通知」/「显示结果」),内容:
   ```
   ₿ BTC
   $美元
   ¥人民币
   24h:涨跌%
   ```
   (把文字中的变量替换成上面命名的魔法变量)

命名为「比特币价格」后:
- 喊 **「嘿 Siri,比特币价格」** 就能播报;
- 在主屏幕添加「快捷指令」小组件,点一下即查看;
- 在「自动化」里设置每天定时运行 →「显示通知」,即可定时推送价格。
